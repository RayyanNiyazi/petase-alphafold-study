# Results

Output tables from the analysis scripts. The file name prefix says which script made each file: single_ and baseline_6EQE_vs_5XJH_ come from compare.ps1, ensemble_ from ensemble.ps1 (26 wild-type chains), family_ from family.ps1 (11 relatives and the blind test), and part2_ from part2.ps1 (ESMFold and FAST-PETase). Running the scripts writes these into subfolders of results/ instead.
